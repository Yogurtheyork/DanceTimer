# Mac / iPhone 驗收清單

以下均為待執行項目，沒有在 Linux 假設已通過。記錄裝置型號、iOS / Xcode 版本、實測結果。

- [ ] Xcode Build 成功，只有一個 `@main`，三項用途說明存在於最終 App Info.plist。
- [ ] 新安裝開啟 App 不立刻要求權限；按啟用後先詢問相機、再詢問麥克風。
- [ ] 分別拒絕相機／麥克風，App 不崩潰、不開始錄影，有說明和設定入口。
- [ ] 從設定開啟權限後回 App，重新啟用相機可成功。
- [ ] 錄影 40、60、自訂 7 秒；回放確認影片時長符合設定（以影片影格邊界容差檢查），準備倒數未被算入。
- [ ] 自訂 0、601 或清空欄位不造成無限制錄影；開始按鈕只接受 1–600。
- [ ] 設定就位時間 0、3、20 秒，各確認一次。
- [ ] 5、4 各約 1 秒，3、2、1 依選擇加速；確認系統提示音、靜音及音量行為。這不是語音喊數。
- [ ] 倒數中取消不產生影片；重複點按不會建立多個錄影。
- [ ] 錄影前最後一個提示音沒有明顯殘留在片頭，影片有同步的現場收音。
- [ ] 提前結束可回放短片；自動到時結束也可正常回放（錄影上限回呼可能帶成功旗標）。
- [ ] 返回主畫面／鎖屏：倒數取消，錄影停止並保留有效片段；回來需重新啟用相機。
- [ ] 來電或相機系統中斷可結束並恢復，狀態不會一直停在「Finishing video…」。
- [ ] 相簿權限只在按儲存時要求；拒絕仍可回放，允許後可在照片 App 找到影片。
- [ ] 重啟 App 後，過去完成的片段仍可回放；檢查沒有損壞或空白影片列。
- [ ] 測試儲存空間不足的錯誤提示，不得顯示假成功。
- [ ] 左下歷史錄影縮圖顯示最新片段、可開啟列表並回放／儲存；關閉後相機自動恢復。右下設定可調整時間，錄影中兩側按鈕停用。
- [ ] 在小尺寸 iPhone、大字體、VoiceOver 下可操作主要按鈕；直向影片不旋轉。
- [ ] 連續錄三次、回放與儲存，沒有卡住、相機無法重新啟動或異常發熱。

已知範圍：不含前鏡頭、橫向、語音倒數與 App 內影片刪除。藍牙與外部音訊裝置的支援尚未承諾，須另行驗證。
